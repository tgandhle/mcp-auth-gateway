# Evidence

`CURRENT.md` is a reproducible local technical-evidence snapshot generated by
`verification/collect_evidence.ps1`. It is tied to an exact commit and records
failed, passed, and unavailable checks without treating missing external
evidence as success.

Evidence rules:

- Never include tokens, private keys, credentials, internal URLs, or production
  payloads.
- Preserve command names, exit codes, timestamps, commit IDs, and concise
  results.
- Regenerate after the approval package is committed so the recorded commit is
  the code that was actually tested.
- Human approvals belong in an environment-specific copy of the approval table;
  automation must leave them `PENDING`.
